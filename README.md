# Drifty-2DProject
First2DgameProject
Hello!

In this project, I have relied heavily on AI to come up with scripting,

Especially when it comes to movement and drifting calculation,

Though ideas and the code are modular enough that I can tweak variables to get the right feeling of the gameplay.

The entire idea of the game was to steer based on the mouse instead of the keyboard input.

I thought to myself that I needed some form of acceleration, momentum, and grip, so I used Rigidbody as the physics engine and collider to track wall collision.

There is a little bit of visual feedback upon hitting the wall, I thought that was cool to add in.

There is a prototype of audio engine, this is something I wish I could have improved on, but for now, the engine plays different sounds based on only speed.

There is an implementation of skid marks, though not too visible,

AI has been used extensively in creating scripts;


Given the one pager, i will say the scope did not drift, though I will say some parts of the scope were not met, such as coins and cones.
